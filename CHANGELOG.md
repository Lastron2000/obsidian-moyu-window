# Changelog

## 1.0.0 (2026-10-28)

Initial release.

- True window transparency through an asar patch (`transparent` + `backgroundMaterial:"none"` + `thickFrame:false`)
- Distraction-free reading mode
- Global, rebindable panic key
- Always-on-top at `screen-saver` level
- Capture protection for screenshots and recordings
- Automatic day/night theme based on wallpaper luminance
- Wallpaper fallback for unpatched installations
